# Blessing Juliana Asumin — Cloud Engineering Portfolio

A recruiter-facing portfolio website showcasing hands-on AWS cloud engineering projects across serverless architecture, CI/CD, automation, security, networking, observability, containers, and Infrastructure as Code.

## Live deployment

This site is designed for GitHub Pages and is pure HTML/CSS/JavaScript with no build step.

## Local preview

Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub Pages deployment

1. Create a public repository, for example `cloud-portfolio`.
2. Push `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will publish the site at `https://<username>.github.io/<repository>/`.

For a user site at `https://julianaasumin.github.io/`, name the repository `julianaasumin.github.io`.

## Project evidence images
Selected project visuals live in `assets/images/`. They are intentionally limited to visuals that prove a working product, architecture, or engineering outcome. Replace an individual image in that folder (using the same filename) to update it without changing the rest of the site.
